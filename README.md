# Web académica de Solia Centeno

Este paquete contiene una versión inicial de sitio web académico para **Solia María Centeno de Baglivo**, inspirado en la lógica de portafolio académico del sitio de Roberta Rosa Valtorta: navegación clara, perfil lateral, páginas de proyectos, publicaciones, docencia, CV y contacto.

## Archivos principales

- `index.html`: página de inicio con presentación académica y áreas de investigación.
- `proyectos.html`: portafolio de proyectos de investigación.
- `publicaciones.html`: libros, tesis, coautorías y futuros productos académicos.
- `docencia.html`: cursos, talleres, filosofía docente y recursos.
- `conferencias.html`: divulgación, conferencias y trabajo público.
- `cv.html`: CV académico breve y lista de datos pendientes.
- `contacto.html`: página de contacto profesional.
- `privacidad.html`: política básica de privacidad.
- `assets/css/style.css`: estilos visuales.
- `assets/js/main.js`: menú móvil y navegación activa.
- `assets/img/`: imágenes SVG de reemplazo.
- `contenido/`: guías, prompt e instrucciones editoriales.

## Cómo usarlo

1. Descomprimir el archivo ZIP.
2. Abrir `index.html` en el navegador para revisar el sitio.
3. Reemplazar las imágenes SVG por fotografías reales:
   - `avatar-placeholder.svg`: fotografía profesional de Solia.
   - `banner-academico.svg`: imagen de campo, biblioteca, comunidad educativa o aula.
   - imágenes de publicaciones: portadas reales de libros o gráficos propios.
4. Editar los enlaces marcados como `#`:
   - ORCID.
   - Google Scholar.
   - ResearchGate.
   - LinkedIn.
   - Enlaces a libros, PDF, videos y entrevistas.
5. Subir los archivos a un hosting estático o integrarlos en WordPress como plantilla base.

## Recomendación editorial

La web debe priorizar:

- Investigación educativa.
- Educación intercultural.
- Políticas públicas.
- Publicaciones verificables.
- Conferencias y participación institucional.
- Recursos para docentes, investigadores y gestores públicos.

Evitar como eje principal del sitio:

- Testimonios demasiado íntimos.
- Contenido esotérico o espiritual no vinculado a investigación.
- Mensajes comerciales o de venta directa.
- Exceso de frases motivacionales sin sustento académico.

## Datos pendientes

Antes de publicar, completar:

- Correo profesional definitivo.
- Foto profesional.
- CV PDF actualizado.
- ISBN y enlaces de libros.
- Enlaces a perfiles académicos.
- Lista verificada de conferencias.
- Instituciones y afiliaciones con nombres oficiales.

## Publicación

Para publicar en `soliacenteno.com`:

- Opción 1: hosting estático con Netlify, Vercel, GitHub Pages o servidor tradicional.
- Opción 2: convertir estas páginas en secciones de WordPress.
- Opción 3: usar este material como guía para crear un sitio en Owlstown, WordPress o Webflow.
