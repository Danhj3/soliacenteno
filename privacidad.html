Política de privacidad

Este sitio académico recopila únicamente la información que el usuario decida enviar mediante correo o formulario de contacto. Los datos se utilizarán solo para responder consultas, invitaciones o propuestas de colaboración.

No se recomienda publicar datos personales sensibles. Si el sitio usa analítica, boletín o formularios externos, se debe actualizar esta página indicando proveedor, finalidad y forma de eliminación de datos.
